SOBRE O PROJETO

INSEP Acessível

O INSEP Acessível foi desenvolvido em equipe com o objetivo de aplicar conceitos de desenvolvimento web, experiência do usuário e acessibilidade digital.

O projeto busca proporcionar uma navegação mais simples, inclusiva e acessível, utilizando diferentes recursos para atender às necessidades dos usuários.
