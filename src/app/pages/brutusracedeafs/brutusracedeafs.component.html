PROJETO VOLUNTÁRIO

Brutus Deaf

Sistema para organização de participantes

Atuei como desenvolvedor voluntário no Brutus Race Deafs, apoiando a organização de um evento esportivo com cerca de 250 participantes.

O processo era manual e baseado em fichas de papel, o que gerava erros, retrabalho e dificuldade na consulta das informações.

Acessar projeto Ver detalhes
SOBRE O PROJETO

Do papel para o digital

Para melhorar a organização do evento, desenvolvi uma solução web integrada ao Google Sheets para centralizar, validar e consultar as informações dos participantes.

A proposta foi reduzir processos manuais e facilitar o trabalho da equipe durante a organização do evento.

Tecnologia utilizada

Frontend Angular, componentes, formulários reativos, rotas e serviços
Backend API REST com Spring Boot
Integração Google Sheets API
Autenticação Login e senha individual
Dados Google Sheets como armazenamento de dados
