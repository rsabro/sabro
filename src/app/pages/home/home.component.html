API via Google Planilhas

Desenvolvi uma solução leve e prática para quem precisa acessar dados via API sem complicações.

Utilizando o Google Planilhas como base de dados, não é necessário servidor, hospedagem ou banco de dados.

Os dados são atualizados diretamente na planilha, e a API responde de forma rápida e simples — ideal para protótipos, projetos pessoais ou integrações leves.
